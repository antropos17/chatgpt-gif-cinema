TRY THE INCLUDED FILM

Three GIFs. One story.
No API key.

Assemble the complete 7.68-second astronaut film.

git clone https://github.com/antropos17/chatgpt-gif-cinema.git
cd chatgpt-gif-cinema
python -m venv .venv
source .venv/bin/activate
python -m pip install .
python -m gif_cinema render examples/film.json --execute --max-api-calls 0 --out output/my-first-film

Requires Python 3.10+, Git, FFmpeg and ffprobe.
Open output/my-first-film/film.mp4 when finished.

About new footage

This example only assembles the bundled footage. New generated action requires supported model access and separately authorized requests.
