## One result, then one local command

The README positions GIF Cinema as a local way to turn GIF shots into short films:
control cuts, inspect source timing and bound optional generation requests. A
request cap is not a dollar limit. The available product is a Python CLI and agent
skill, not a hosted editor or the separate private browser editor.

**Lantern Echo** remains the featured 20.8-second authored anime film with sound.
Its single 6.4-second silent GIF excerpt links to the immutable full MP4 download
and includes the existing reduced-motion poster. The production note distinguishes
new drawings, prepared external RIFE interpolation and authored finishing from
the public CLI. Download availability is not a claim about inline browser playback.

After installing Python dependencies and FFmpeg/ffprobe, `python tools/demo.py`
builds the bundled three-shot, 7.68-second silent film with zero provider calls.
The launcher reports prerequisites and chooses a fresh output directory. It does
not silently install anything or overwrite an earlier result. The detailed setup,
direct CLI commands, reuse instructions and optional exact-frame master stay linked.
A successful decode is not artistic acceptance or seamless character continuity.
