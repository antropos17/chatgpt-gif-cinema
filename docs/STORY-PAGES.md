# Existing GIF actions, readable story pages

GIF Cinema can now compose a short illustrated book from existing GIF takes and
editable page text, entirely offline. Landscape places the words left of the
action; portrait places them below. Source cadence is preserved and each action
plays once. This adds actual GIF page exports, not just storyboard planning.

[Commands, schema, portable projects and limits](../.agents/skills/gif-cinema/references/story-pages.md)

The included recipe creates three 960 × 640 pages, each 2.56 seconds long, from the
existing astronaut footage. It does not make new astronaut actions or claim
GIF Factory's visual-quality breadth. Use the emitted `film.json` for a silent
7.68-second MP4. No new media, fonts, API credentials or generated artwork are
committed with this change. No paid calls are required.

The page layout is an original implementation inspired by the general illustrated
storybook workflow. No GIF Factory artwork, fonts or compositor code are copied.
The project's source-available license and existing third-party notices are
unchanged. Font and source-media sharing rights remain the user's responsibility.
